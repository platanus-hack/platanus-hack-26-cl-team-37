# Prompt 3: catálogo de ejercicios

Adjuntar: imagenes/03_ejercicios.png

---

Adjunto 03_ejercicios.png. Construye /ejercicios.

- Crea un registro de juegos (games/registry) con: id, nombre, gestos que trabaja, niveles, ruta y miniatura.
- "Caja de juguetes" es el único juego real: regístralo con la ruta actual. Los demás (Torre de cubos, Pinza fina, Atrapa burbujas) aparecen como "Próximamente" y no se pueden abrir.
- Filtros por gesto: Todos, Pinza, Agarre, Alcance.
- Cada tarjeta muestra miniatura, nombre, gestos y nivel actual del paciente. Etiqueta "Asignado" si el juego está en su plan.
- Tocar un juego disponible lleva a /sesion/:juego/preparar.
